# Scripts — `script-architect/`

Create section of UGC OS. This file loads when Claude works with files under `src/apps/script-architect/`; the app-wide rules stay in the root [CLAUDE.md](../../../CLAUDE.md).

## Job

**The member picks who writes** — a `ScriptModelRow` pinned **directly above Generate** (it applies to both modes, it's the last thing you'd change before firing, and it's what decides what the click costs). Above it, a **Variations / Length pair of `Dropdown`s** sharing one row, both opening upward — they were two full-width `SegmentedToggle` slabs, which cost the brief its height for controls nobody sweeps through; each hides on its own (Hooks has neither, the blueprint rewrite has neither, Remix's Length leads with **Default**). Two modes: **Remix** (one source box; format auto-detected via `detectSceneBlueprint` — a winning transcript → 3 variations, an Ad Analyzer scene blueprint (`--- Scene N` / `SCENE N —` headers) → rewritten scene prompts, with a chip to override back to plain remix) and **Write New** (brief + style + 10/15/20/30/60/90s → 3 human-sounding takes, as plain script or scene blueprint). **Both modes pick a length** above Generate, but Remix's list leads with **Default** (`REMIX_LENGTHS`, its own persisted slot `:remixLength`) — the source ad already has a length and keeping it is usually the point of remixing a winner, so 'default' sends no target and the numbers re-cut the source to a duration. Hidden for the blueprint rewrite, which holds the source's own scene timestamps. The three LLM pipelines and `ScriptMode` ('write' / 'remix' / 'reverse-engineer') survive unchanged in the service and history rows — only the UI toggle merged. Write New's **Output** toggle: Script / Hooks / Scenes. **Script Style is two groups in one picker** (`WriteStyleGroup`, sectioned in the slide-over, **Formats on top** — `ScriptStyleList formatsFirst`, in both apps): **Formats** — the kind of organic content the ad imitates (podcast clip, street interview, green-screen reaction, comment reply, expert explainer, how-to, GRWM), the higher-converting half because the ad reads as content before it reads as an ad, and the only half that decides the shots — over **Structures**, the persuasion mechanic (PAS, story, 3 Reasons, callout, curiosity, before/after, demo, us-vs-them, objection-crusher, founder). Only formats carry `WRITE_STYLE_SCENE_DIRECTION`, appended in the **Scenes** output so the blueprint actually stages the format (boom mic + studio angles, a handheld mic entering frame off a street, an on-screen review card) instead of defaulting to selfie-to-camera; a structure implies no camera, so its shots stay free. B-Roll reaches the same block through `sceneStagingFor` when an analysed ad supplies the staging (it no longer has a format picker of its own — see its row) — `ScriptStyleList` is likewise shared, since the slugs are persisted and two copies of the list would drift into a wrong label on somebody's saved session. When a format's way of opening collides with the take's opening device, `FORMAT_OVERRIDES_TAKE` gives the format the delivery and the take keeps its angle. Style slugs are **stable** — they key persisted picks and history rows. **Hooks** (`writeFormat: 'hooks'`) writes 10 standalone opening lines from the "1,000 Viral Hooks" swipe file distilled into 7 formula families (`HOOK_CATEGORY_META`: Educational / Comparison / Myth Busting / Storytelling / Authority / Day in the Life / Pattern Interrupt); the Hook Style picker defaults to **Best Mix** (LLM picks ≥4 fitting families) or locks one family; no length/style controls; a single LLM call returns `<FAMILY>`-tagged lines (`parseHooks`) rendered as per-hook rows with a family chip + copy — copy/save strip the tags, and there are no send buttons. Formulas are kept at full original length (setup + payoff, never truncated), and the same `HOOK_LIBRARY` + `HOOK_OPENING_INSTRUCTION` seed the opening line of Write New's Script and Scenes outputs. **Cinematic is retired** (July 2026): a fourth `writeFormat: 'prompt'` that wrote one ≤15s single-clip AI-commercial master prompt (STYLE→TIMELINE sections, `@INFLUENCER`/`@PRODUCT` tokens) and shipped it to Playground video mode. Its toggle entry, influencer picker, service pipeline and `cinematicVideo` handoff are deleted (see git history to restore); what stays is `ScriptHistoryItem.writeFormat: 'prompt'` on rows already on members' accounts — `isWriteFormat` coerces those to `'script'` on restore, and History still badges them "Cinematic". **Scene tokens:** `[PRODUCT]` / `[CHARACTER]` are reference-image slots and belong in **visual direction only** — never inside a spoken line, which TTS and video models pronounce literally. Dialogue always names the product in plain words, at most twice (`nameSpokenTokensInDialogue` is the deterministic backstop when the model ignores that). **Batch size is user-picked — 3 / 5 / 10, default 3** (`VARIATION_COUNTS`, the Variations `Dropdown` above Generate — its options carry the noun ("3 variations") and it therefore takes no dim `label`, which would have read "Variations 3 variations"; Length keeps its label, since "15s" alone doesn't say what it measures. Hooks exempt and hidden, `HOOK_COUNT` stays 10). Five parallel takes off one brief crowded each other, so 3 is the default, but the wide net stays one click away. Every angle list (`WRITE_TAKES`, `REMIX_ANGLES`) holds **10 entries ordered strongest-first** and is **sliced** to the chosen count — so picking 3 gets the three best angles, and a count can never index past its pool. **The batch spreads the angle only when the creator left it open** (`CREATOR_ANGLE_PRECEDENCE`, appended LAST to both pipelines' angle block so it beats the assigned anchor): a brief or Additional Context that names the angle — a pain point, benefit, feature, audience, story, hook — is written by every variation, which then differ only in opening device. Where the creator says nothing, `takeAngleBlock` tells each take, in one phrase each (`WRITE_TAKES[].label`, kept beside the instruction it summarises so the two can't drift), what its siblings are anchored to and to stay off them — takes are parallel calls blind to each other, so a product with one obvious pain point otherwise comes back as three near-identical scripts. `RemixAngle` has 10 members; `hook-led` sits LAST because as an angle it mostly restates the global hook rules. A remix **stamps the angles it used** onto `GeneratedScript` + the history row (`remixAngles`, `variationCount`) and `OutputPanel` prefers that stamp; rows saved before the picker carry no stamp and are matched by count via `remixAnglesForCount`, which keeps the pre-picker five-variation order distinct from today's first five (a different set). The Output tab's empty + generating states render on the shared `GridCanvas` (the grid goes once takes land), the generating skeleton carries the scripts glow, and the header's **+** clears the panel back to the empty canvas — every take is already a History row. **The take switcher is a scroll-jump, not tabs** — every take stays in one continuous column and the 1/2/3 row scrolls to one (and re-highlights as you scroll past). Rendering a single take at a time was tried and rejected: reading straight through the takes is worth more than putting each take's action row on screen. **A scene card splits the spoken line out of the direction** (`splitSpokenLines`): the prompt contract quotes dialogue inline as `[CHARACTER] says: "…"`, and that quoted line — the only part that's read aloud, recorded, and sent to Voiceovers — renders as its own tinted, separately-copyable block above dim direction prose. Two guards earn their keep: a quote with **no attribution in front of it stays in the direction** (a scare quote like `a visible "wait, what?" reaction` was being promoted to dialogue and cutting the sentence in half), and the speaker can't be a connective (`…and says:` labelled the line "it over and"). Anything unrecognised falls back to the old single prose block, so no shape can render empty. `[CHARACTER]`/`[PRODUCT]` are tinted inline text, **not pills** — an inline-block pill fractured line-breaking and orphaned the possessive in `[CHARACTER]'s hands`. `splitHeaderLine` lets a header carry its own prose (`SCENE 2 — B-ROLL DETAIL: <prose>`), since assuming the header owned the whole line dropped the body and left blueprints of single-line scenes rendering as "0 scenes".
