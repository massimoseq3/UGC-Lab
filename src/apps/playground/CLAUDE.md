# Playground — `playground/`

Create section of UGC OS — the dock tile sits between B-Roll and Edit. This file loads when Claude works with files under `src/apps/playground/`; the app-wide rules stay in the root [CLAUDE.md](../../../CLAUDE.md).

## Job

Free-form Image / Video / Music — tabs in that order, landing on **Image**, because the loop it's used for is "make a still, then animate it". That loop is one click: an image tile's hover stack (and the preview modal) carries an **Animate** action that switches to Video with the still inlined as the start frame and the prompt that made it seeded in the bar (`handleAnimateImage`), going through the same `promptStash` as a manual tab switch so the Image tab keeps its own draft. Each mode remembers its own model under `playground:<task>[:<mode>]` — Image/Music via `ModelPicker`'s own persistence, Video written by the panel itself since `ModelSidePanel` leaves persistence to its caller; without that write every Image → Video flip reset the pick to the registry default. Prompt bar, mode tabs, model picker, model-aware ref slots + drag-drop (images everywhere; Seedance 2 adds audio/video reference clips; Gemini Omni adds characters / designed voices / a trimmed source clip under a 7-slot quota). `@`-mentions reference Products / Influencers / B-Rolls and auto-attach the asset. Uploaded audio/video refs are memory-only (pruned from the persisted draft — too big for localStorage).

**Omni's characters are a 2-column grid of `MediaCard`, matching voices and the source clip** — the three Omni-only inputs read as one list of attachments instead of a tile grid stacked over two card lists. `MediaCard` takes a `thumb` so the character still shows its face in the icon chip's place, and no `accent`: a tint that marks bank-backed rows made one of the three look like a different kind of thing. **Reference images stay 64px `ImageTile` squares with a dashed add tile**, in both Image and Video mode — they were briefly cards too and it was reverted, because on a reference image the PICTURE is the point and a 28px chip beside a filename makes "did I attach the right photo?" the smallest thing on the row. The frame slots (start / end) are `aspect-[2/1]`, not 16:9 — they sit directly above the prompt box and every pixel there is one it loses; the frame inside is `object-contain`, so the ratio only sets the slot's height.

**Download clips** — the history header's neutral pill on the Video tab opens the shared `components/ClipDownloadModal` (lifted out of B-Roll so the two can't drift), which zips whatever stays ticked. It opens with **nothing picked**, unlike B-Roll's, which pre-ticks each card's cover take: B-Roll's list is one storyboard, this one is every clip the member has ever generated here, so opening it all-ticked would mean unticking dozens to get the two they came for. A video row carries no title, so the label is its prompt (clamped to two lines) over a relative-time meta line — the model name was on that line and came off, since it's the same for a whole run and so tells no two clips apart — and the zip name is positional (`playground-clip-03`) since `playground-${id}` is unique but unreadable in a folder. Video only — the picker previews with a `<video>`, and images/music already download one-tap from their tiles.
