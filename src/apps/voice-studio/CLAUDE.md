# Voiceovers — `voice-studio/`

Create section of UGC OS. This file loads when Claude works with files under `src/apps/voice-studio/`; the app-wide rules stay in the root [CLAUDE.md](../../../CLAUDE.md).

## Job

Script → audio (Gemini 3.1 Flash TTS). 30 named Google voices, picker **grouped by gender** (Female 14 / Male 16, split per Google's docs; each voice keeps a vibe descriptor tag). The picker generates a short sample **on demand** and caches it per session (`services/previewVoice.ts`) since Gemini has no hosted preview files. Side panel order (it sits on the LEFT, with the script editor to its right — the only app whose controls column isn't the input column): **Preset** → Voice → Style → Pace+Accent → Expressiveness → Tone/context → Scene. The **Preset** row loads a saved `voices` bank entry through `PresetPickerView` (`settingsFromPreset` flattens it through `sanitizeVoiceSettings`, so a preset written against an older option list still loads) — voice, delivery params AND its scene/tone in one tap. It is **not** a `BankPicker` slide-over: picking a preset and picking a voice are the same gesture one after the other, so both are in-panel views that take over the side panel (`SidePanel` owns both flags and hides the tab strip while either is up), sharing the header / search / row shape and the tap-the-avatar sample preview (`useVoicePreview`); presets carry `scene`/`sampleContext`, editable in the Bank's `VoiceForm`. The row's stamp (`VoiceSettings.presetId`/`presetLabel`, label-only, never sent to kie) is dropped by ANY hand edit — every control in `SettingsView` goes through one `update()` helper, plus the voice picker, "Reset values" and a history restore — so the row can't name a preset the settings no longer hold. `style` / `pace` / `accent` are custom portaled `Dropdown`s (via `AnchoredPopover`) whose options are kie.ai's **exact** enums — Style (Vocal Smile/Newscaster/Whisper/Empathetic/Promo·Hype/Deadpan, default Vocal Smile not kie's Deadpan), Pace (Natural/Rapid Fire/The Drift/Staccato), Accent (Neutral/American Gen·Valley·South/British RP·Brixton/Transatlantic/Australian) — verified at kie.ai/gemini-3.1-flash-tts; don't invent values. `temperature` is the "Expressiveness" slider; `scene`/`sampleContext` optional. `voiceId` holds the Gemini `voice_name`. `sanitizeVoiceSettings` coerces persisted style/pace/accent that predate an option-list change. **History is a card list, not thin rows** — a voiceover has no thumbnail, so the card carries the clip itself: a 48px play button (the voice's `seedColor` avatar doubles as it, so the colour still says who is speaking) over the voice name + "3h ago · 0:06", and the script preview under it. **The waveform belongs to playback** — the strip is collapsed until the play button is pressed and closes again when the clip ends, because a card at rest is a thing you read, not a thing you watch. `Waveform.tsx` draws the **whole clip at rest and fills it left to right as it plays** (SoundCloud-style), and a click anywhere on it seeks. The peaks are decoded once per asset from the audio itself (`waveformPeaks` in `audio.ts`: fetch → `decodeAudioData` on an **Offline**AudioContext → 56 peak buckets, square-root curved so it isn't a flat line with two spikes, normalised to the loudest bar, cached by asset ref). It replaced a live spectrum analyser that failed in both directions: the analyser's default ceiling (`maxDecibels` −30) sits BELOW where a normalised voiceover plays, so every band pinned at 255 and a loud clip rendered as 44 bars flat out at full height — and routing the `<audio>` element through an `AnalyserNode` meant a suspended AudioContext played the clip **silently**. Decoded peaks touch nothing on the playback path, so that whole class of bug is gone with it. `audio.ts` holds the plumbing: the one-clip-at-a-time slot (the audio counterpart of `useInlineVideo`'s rule — cards and `BottomPlayer` register a pause fn, so play on one stops the other), `resolveAudioUrl`, and the peak decoder. **Never trade sound for a visual** is the rule that shaped it: nothing the waveform does may touch the element that's playing.
