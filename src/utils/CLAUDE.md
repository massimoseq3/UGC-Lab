# CLAUDE.md — the model registry (`src/utils/`)

`models.ts` is the single source of truth for every model the app can call: add or
change one **only** by editing that file, never by sprinkling slugs through services.
The root `CLAUDE.md` carries the defaults table and the registry-wide rules; **this
file is the per-model detail** — why each default holds its slot, what has held it
before and handed it back, and the pricing and capability caveats to re-verify.
Read the relevant section before promoting, demoting or removing a model.

What to watch while they agree: nothing is exercising the cheap/strong distinction, so a price move on this single row moves the cost of every chat call in the app at once — and the promo caveat in the row below is now an app-wide caveat. ## Registry mechanics

- **Official pricing / savings.** `ModelEntry.official` = `{ usdFor(opts), source }` — the provider's own API list price; chat entries build theirs with the `chatOfficial(inUsdPerM, outUsdPerM, source)` helper, which blends input/output 50/50 exactly as `pricing.credits` does so the "% off" chip compares like with like — and `ModelEntry.market` — a verified creator-platform price (Higgsfield etc.). Both only added when verified (source URL in the entry; return `null` for tiers with no comparable rate — unknown savings count as zero, never invented). `CREDITS_PER_USD = 200` ($0.005/credit). `officialSavingsPercent(modelId)` (official-only) drives the green "% off" chip in ModelPicker + ModelSidePanel — **on the row's META line, beside the credits it is a discount ON** (Massimo's call, September 2026; it sat on the NAME line, a green block interrupting the one thing a row is scanned for, two lines above the number it refers to — `ScriptModelRow` had always had it right); on a collapsed TRIGGER it lives in `components/ModelTriggerLabel.tsx` — the shared name + star + pill block, extracted once because six triggers had hand-rolled it — where **the pill collapses before the name truncates**. It is a CONTAINER query (`@container` on the label, `hidden @[200px]:inline-block` on the pill), never a viewport one: what squeezes these rows is the PANE, so a `md:` rule would drop the pill on a phone where the trigger is full-width and keep it on a 1400px desktop where the trigger is 210px and the row read "GPT I…". The Dashboard's money-saved metric compares kie against `max(official, market)` per generation (USD appears there deliberately). Seedance 2.0 family has NO official entry on purpose — kie beats Fal but not BytePlus direct, so we claim nothing (see registry comment).
- **Motion Control** (`kling-3.0/motion-control`, Playground only; a cheaper Kling 2.6 entry sat beside it and was removed July 2026). Flagged `motionControl: true`; mode is fixed (not inferred). Takes a required character image + driving video (`input_urls` / `video_urls`) and a `character_orientation` ('video' ≤30s / 'image' ≤10s); prompt optional, no aspect/duration/audio. Playground swaps the ref panel for `MotionControlSection` (image slot + driving-clip upload + orientation toggle) via the `motion-image` / `motion-video` ref slots; the driving clip is memory-only (pruned from the persisted draft). Per-second billing keyed on 720p/1080p.
- **Gemini Omni Flash 1.1** (`google/gemini-omni-flash-1-1`). Its *extra inputs* (characters / designed voices / source clip) are Playground-only UI — B-Roll drives it with plain reference images. Three capability flags on `ModelEntry`: `supportsReferenceAudio` / `supportsReferenceVideos` (Seedance 2 family — `reference_audio_urls` / `reference_video_urls`, validated client-side via `utils/media.ts` metadata reads against `referenceClipCapacitySeconds`: ≤15s total each by default, ≤30s where a model declares `maxReferenceClipSeconds`) and `omniInputs` (Gemini Omni Flash 1.1 alone, now that 1.0 is gone — it is a capability flag, not an id check, which is what let the whole Playground omni UI survive that removal untouched). Omni inputs share a 7-slot quota (image ×1, source clip ×2, character ×1). Characters come from the Influencers bank — `ensureOmniCharacterId` (playground/service.ts) mints the id via `/omni/character/create` on first attach and stamps `Model.omniCharacterId`. Designed voices live browser-locally in `stores/omniVoiceStore.ts` (like the kie key — ids are kie-account-scoped). Omni audio is always on (no toggle); a video input switches billing to a flat per-call tier (`PriceParams.videoInput`).
